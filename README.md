# Vibe Check

Vibe check is an easy tool for getting better prompts for coding.

Just write your query,

make it better,

then copy the prompt to Cursor, ChatGPT, Claude, v0, Bolt, or any other coding tool.

## What does it do?

Improve simple prompts

Check prompt quality

Compare before and after

Prompt templates

Prompt history

Prompt variations

Detect common tech stacks

Remove extra words

Save data in Local Storage

Export your prompts

Optional API

## Built With

HTML, CSS, and JavaScript. No front-end framework needed.

## To run this project locally

```bash

git clone https://github.com/tallurisai9346-beep/Enhance-Prompts.git

cd Enhance-Prompts

npx serve .

```

you can also open the file directly in the browser

## API

The following route is used in the app

```

POST /api/enhance

```

in the case of failure to connect to the API, a local API is used

## project file structure

```

vibe-check-rewitten.html

```

everything is in one file for simplicity
