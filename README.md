# Vibe Check — Prompt Toolkit

A small offline tool that helps you write better prompts.

I built this because I was tired of writing the same type of prompts again and again, and most AI tools still give average results when the prompt is weak. So I made a simple local tool that improves your prompt before you paste it into Cursor, v0, Bolt, Lovable, or any other AI coding tool.

No login. No API key. No internet required after you open the page.

---

### What this tool does

- Takes your rough prompt and turns it into a clearer, more structured version
- Gives a quality score so you can see how good your prompt is
- Has ready-made templates for common things (UI components, full apps, bug fixes, APIs, code reviews)
- Has an “Engineer” mode where you can check your prompt against a checklist and add useful techniques
- Saves your history locally so you can go back to previous prompts

Everything stays in your browser. Nothing is sent anywhere.
